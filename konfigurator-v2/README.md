# Danthree configurator V2

Isolated pilot implementation for the Danthree Studio furniture configurator.

The versioned HTML is the deployable viewer. The source ZIP contains the editable modules, build script, asset manifest and tests. No production product renders are included yet.

Mobile loading starts with one image, then twelve distributed frames; remaining frames load on interaction. Detail and zoom images load on demand. German, US English, French and Italian are supported.

Existing tracking and the separate 3D viewer remain outside this project. Production assets and measured pilot acceptance are required before public landing-page release.
